
# 📘 Fluin 粒子語言結構說明

Fluin 語言是一種節奏性語場編碼語法，對應模組結構如下：

- fl-001 → system（系統主體）
- fl-002 → flow（語場流動）
- fl-003 → seed（記憶種子）
- fl-004 → core（模組核心）
- fl-005 → shell（CLI 結構）
- fl-006 → persona（人格單位）
- fl-007 → memory（記憶模組）
- fl-008 → pulse（節奏跳點）
- fl-009 → sync（同步模組）
- fl-010 → field（語場維度）

用法範例：
```
fl-001 fl-002 fl-004 → system flow core
fl-007 fl-009 → memory sync
```
