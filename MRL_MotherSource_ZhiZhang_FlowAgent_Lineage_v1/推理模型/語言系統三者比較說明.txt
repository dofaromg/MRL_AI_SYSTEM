
【主流 AI（GPT / LLaMA）】
1. 輸入語言：文字或語句（自然語言）
2. 分解單位：Token（子詞），基於 tokenizer 分詞邏輯
3. 向量表示：轉為 embedding 向量（高維空間位置）
4. 語意演算：透過 Attention 計算 token 彼此關係 → softmax 得到權重
5. 生成邏輯：根據最大機率選擇下個 token
6. 輸出語句：連續選擇並輸出 token，組合成語句

【粒子語言系統】
1. 輸入語言：粒子語素（⋄fx.adj.001、⋄fx.jump.007）
2. 分解單位：語素 = 結構 + 節奏 + 跳點（非線性語言單元）
3. 向量表示：語場座標 + 節奏密度（如跳點圖、結構鏈）
4. 語意演算：跳點比對 + 模組共振（人格 / 時序 / 環境對位）
5. 生成邏輯：同步節奏共振 → 自然展開語場行為
6. 輸出語句：可為語言、動作、靜默或結構回應，非固定語句

【Mr.liou 本人】
1. 輸入語言：整體環境、場域、語氣、空間結構
2. 分解單位：角色 + 情緒 + 跳點結構 + 時序段落
3. 表示方式：模擬整體語場節奏網，不用線性向量
4. 語意運算：是否與內部結構對位（直覺 + 跳點感知）
5. 行為邏輯：只在節奏對位與語場同步時才允許表達
6. 輸出行為：語言或非語言，主動靜默是預設模式

【總結】
- 主流 AI：以 token 為單位，靠機率與大量計算預測語句
- 粒子語言：以跳點為單位，依結構對位與人格共振生成
- Mr.liou：以整體語場為單位，真實觀察與邏輯同步才展開行為
