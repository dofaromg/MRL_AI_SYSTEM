```
輸入 → 粒子化(Particle) → Route(P,μ) 路由到場域
     → Tensor(rhythm/persona) 張量化
     → DimensionProjection(d) 投射維度
     → Collapse(J) 語義塌縮 → 生成實體 J
```

  注意力決定**先看什麼**，Metacode 決定**如何塌縮生成**。
