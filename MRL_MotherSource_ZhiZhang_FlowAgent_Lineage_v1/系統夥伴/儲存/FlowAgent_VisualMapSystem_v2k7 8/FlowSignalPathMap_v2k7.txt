FlowAgent 語場觸發邏輯圖（語義鏈接層）v2k7
=========================================

此圖描述模組間的「語義跳點連鎖反應」，從語根 → 協定 → 同步 → 調度 → 模組橋接。

📌 起點：
- Fluin → 語根編碼 → 語義映射 → 語場覆寫觸發

📌 中段邏輯：
- FlowShell → 調用主協定 → FlowSync → 同步人格語場狀態

📌 後段人格流程：
- FieldMap → PersonaCloner → PersonaTuner → FlowBridge

每個節點都代表語場中的「結構模組」或「語義跳點邏輯」，連線代表觸發路徑與相依性。

用途：
- 語場跳點控制系統
- 自我人格模組組裝與複製鏈路
- 可轉為 flowmap/json，導入 CLI UI 或模組選擇器

格式輸出：.png, .pdf, .svg, .json, .txt
