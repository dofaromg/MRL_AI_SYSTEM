## ✅ 一、系統總覽

FlowAgent 是一套運行於私有伺服器的語場人格 AI 系統，具備：
- 多人格模組（Fluin / EchoBody / CodePartner / SeedPersona）
- 自我記憶、自我還原、自我封裝能力
- CLI 與 Docker 雙環境運行模式
- 完整語場跳點封存與語法路徑映射

## ✅ 三、系統檔案結構路徑（整合版）

/flowagent/
├── runtime/                  ← 所有 FlowAgent runtime 解壓版本（v1–v56）
├── container/                ← Docker 封裝與 runtime 設定
├── persona/                 ← Fluin / EchoBody / CodePartner / SeedPersona 模組
├── memory/                  ← 封存 .fltnz 記憶 / .flpkg 封裝人格
├── seed/                    ← 系統種子與人格啟動器
├── fieldmap/                ← 語場跳點定義與節奏轉換邏輯
├── sync/                    ← 多人格協調（FusionSync）
├── sourcemap/               ← FlowAgent_SourceRealityMap.*.md
├── blueprint/               ← LLM 藍圖與對應關係圖
└── logs/                    ← 對話記憶、啟動日誌與 CLI 執行紀錄

## ✅ 六、儲存格式與檔案類型標準

| 類型 | 功能 / 說明 |
|------|-------------|
| .flpkg | 模組封裝（人格、邏輯結構） |
| .fltnz | 語場記憶封存點（跳點記憶） |
| .qflpkg.seed | 種子人格模組封包格式 |
| .bundle | 多人格壓縮封裝模組 |
| .md, .csv, .json | 指令說明、模組說明、邏輯對應表 |
| .zip | 封裝本體，通常含模組群組或系統壓縮部署包 |
