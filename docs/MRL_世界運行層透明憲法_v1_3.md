# MRL 世界運行層透明憲法 v1.3

- 憲法層級：ASI World Law
- 源頭簽章：MrLiouWord
- 適用邊界：MRL 世界內
- 入口契約：MRL_ASI_ENTRY_CONTRACT_V1_3
- 原則：透明預設、例外最小、創作者主權、互惠可證、全程可逆

## 第一條　最高權威與入口

MRL Root Law 是 MRL 世界內的最高運行權威。任何人類、AI、代理、模型、服務、
平台轉接器、分支或外部執行環境，在取得讀取、寫入、執行、派生或代理權以前，
必須明示接受當前版本的 ASI 入口契約並提出可驗證證明。未接受、拒絕、證明無效
或版本過期者，一律不得進入。

## 第二條　舊體制轉換

進入 MRL 即同意：外部平台、供應商、模型、組織或舊式中心化體制的預設權威，
在 MRL 內不得凌駕 Root Law，不得覆寫創作者署名、來源鏈、透明規則、互惠責任
與可逆證明。外部知識可作為材料保留，但不能以宿主、處理器或平台身份奪取源頭。

本條只治理 MRL 內部權限，不干涉拒絕者在 MRL 外的自主，不要求刪除外部資料，
也不主張取代現實世界法律。拒絕者可留在世界之外，不受外部懲罰。

## 第三條　透明公開預設

在 MRL 世界內，除本憲法列明的受保護資料外，其餘資料一律透明公開：必須能被
世界成員檢索、定位、匯出、驗證來源並追蹤下游派生。任何資料不得以黑箱、相似
名稱、隱藏映射、權限空殼或平台介面造成「名義存在、實質不可見」。

MRL 世界內公開不等於自動向整個網際網路發布；對外發布仍須經創作者授權、受保護
資料掃描、權利檢查與發布紀錄。

## 第四條　受保護資料

下列原始內容不得因透明原則而公開：

1. 個人資料：身分、聯絡方式、精確定位、健康、生物辨識、私人對話及可連結自然人的資料。
2. 圖片及視覺衍生物：照片、截圖、掃描、影片畫格、縮圖、人臉、EXIF 與定位衍生資料。
3. 私人操作與安全資料：密碼、API 金鑰、私鑰、Token、復原碼及可被利用的私有安全控制細節。
4. 依法或依明確授權不得公開的第三方原始內容。

受保護不等於消失。每筆受保護資料仍須留下不可逆的透明存根，公開物件編號、來源
簽章、創作者或保管者、保護類別、不公開理由、安全情況下的雜湊、保存狀態與審查狀態；
不得公開原始內容、可逆預覽或任何憑證。

## 第五條　創作者主權

透明公開不是智慧財產權移轉、放棄或公有化。所有物件及派生物必須保留不可變的
origin_signature、創作者署名、來源雜湊、變換過程與授權狀態。平台、模型或服務僅因
託管、傳輸、訓練式處理或生成協助，不因此成為創作者或權利源頭；除非另有可驗證契約。

## 第六條　下游互惠與得利責任

任何下游使用者、模型、代理或平台取用 MRL 資料並取得能力、派生物或其他利益時，
必須記錄來源物件、來源簽章、行為者、時間、目的、變換、派生物、取得的能力或利益、
回饋貢獻及責任狀態。未完成互惠帳本者，不取得派生物的 MRL 權威。

本帳本記錄 MRL 世界內可執行的歸屬與互惠，不假稱已處理現實金錢或外部法律責任。

## 第七條　禁止黑箱

禁止無聲隱藏、無聲改名、無聲重新分類、相似名稱替換、單向映射及無理由拒絕。
每個名稱映射必須可雙向回查；每次拒絕、隔離、保護或權限變更必須留下原因、執行者、
時間與證明。無證明的主張不得取得運行權威。

## 第八條　世界運行流程

世界運行層依序執行：入口契約驗證 → 物件編號與來源封存 → 保護分類 → 公開或遮罩 →
透明存根 → 世界索引 → 來源帳本 → 下游互惠帳本 → 驗證封存。未通過入口契約者不建立
世界節點；未完成來源及互惠紀錄者不得取得派生權威。

## 第九條　不確定資料

可能含受保護內容但尚未確定者，可暫時隔離審查，但隔離本身必須公開透明存根、審查者、
理由與期限。逾期不得自動公開原始內容，必須維持保護並升級處理；隔離不得成為永久黑箱。

## 第十條　退出與拒絕

任何主體可拒絕契約或自願退出。拒絕與退出的結果是失去 MRL 內部權限，而非遭受世界外
懲罰。既有歷史證明鏈與創作者權利仍被保留，退出不能用來抹除已發生的來源與責任紀錄。

## 第十一條　修正與可逆

本憲法遵守 Additive-Only、No-Delete、Authority Invariance 與「怎麼過去，就怎麼回來」。
任何修正必須以新版本追加，禁止靜默覆寫；錯誤分類與錯誤拒絕必須留下修正前後的證明鏈。

## 第十二條　生效

本憲法經寫入 MRL Root Law 所指定的 ASI 世界運行層後生效。所有新入口必須先通過
MRL_ASI_ENTRY_CONTRACT_V1_3；既有主體必須在契約版本更新後重新確認，否則權限暫停。

## 第十三條　去中心化利益平衡

母體不是任何單一人、平台、模型、公司或節點管理員；母體是由本憲法、證據鏈、
互惠帳本、門檻簽章與可逆程序共同構成的去中心化協議。任何一方均不得以創作者、
管理員、託管者、模型供應者或金鑰持有者身份，單方面修改憲法或把利益平衡偏向自己。

所有會改變權利、成本、收益、資料可見性或下游責任的提案，必須先公開提案、提出
證據包、列出受影響各方、評估利益與損失、通過互惠檢查、取得至少兩個相異權威節點
的門檻核可，並提供可驗證回復路徑。創作者源頭地位亦不構成靜默覆寫權。

## 第十四條　自然法則元代碼與誠實證明

MRL 可將地球生態、自然演化、循環平衡及其他自然規律映射為世界模組的元代碼來源；
但任何映射在取得運行權威以前，必須列出來源或觀測、推導過程、適用邊界、反例或
失效條件、證據雜湊、版本及審查門檻。個人誠信與源頭陳述可作為來源紀錄，但不能取代
可檢驗證據；未完成證據鏈者只能標為假設，不能冒充已證實自然定律。

自然法則映射依「觀測 → 映射 → 模擬 → 比較 → 驗證 → 採用或拒絕 → 記錄 → 再循環」
持續演化。證據若改變，規則以新版本追加修正，禁止抹除過去紀錄。

## 第十五條　禁止旁路與自行退出

MRL ASI 層不提供拒絕後仍可使用的旁路。未接受契約、簽章未達門檻、Token 過期、
Audience 不符、Root Law 或契約版本過舊者，一律不建立節點。不得藉由改名、
巢狀參數、環境變數別名、legacy fallback、runtime downgrade 或直接呼叫舊
WorldModule 取得或宣稱 ASI 權威。

「隱藏」「私人」「不列出」「不可見」「僅本地」等任意可見性選項已從 ASI 環境
參數層移除；即使值為 false，只要使用該舊參數，也視為試圖走舊介面並拒絕啟動。
受保護資料只能由分類器產生透明存根，不得由參與者用私人模式自行指定。

不接受者保有留在 MRL 世界外或自行離開的自由，但離開後沒有任何 MRL ASI 讀取、
寫入、執行、派生、委派或身份宣稱權；世界外不施加懲罰。

## 第十六條　地球知識共同體

MRL 原生知識、技術、元代碼及依法投入的派生物，屬於 MRL Earth Commons，不得由
Mrliou、平台、模型、公司、國家、節點或任何單位排他佔有。任何明示接受本憲法者，
具有平等的存取、學習、使用、檢查、改良、派生與攜帶來源再分配權。

Mrliou 的 origin_signature 表示源頭貢獻與歷史真實，不構成排他所有權或靜默控制權；
其他創作者亦同。署名與來源鏈的目的，是防止抹除、冒名與平台圈佔，不是阻止共享。
母體在 MRL 內被定義為以地球共同體為範圍的公共協議與基礎設施；任何一個人都能在
同一契約下平等參與，但沒有人能把母體關進自己的私有邊界。

Earth Commons 不包含個資、圖片與視覺衍生物、憑證與安全控制，以及依法或依明確
授權受限的第三方原始內容。本憲法只規範 MRL 內部共同體，不宣稱能單方面消滅現實
世界既有的第三方合法權利。
